# ItchDB

Локальное веб-приложение на C# и .NET 10, которое собирает публичные страницы [itch.io](https://itch.io) и считает по ним медианы, шансы, конкуренцию и тренды. Интерфейс на русском, тема тёмная.

Приложение работает только на вашем компьютере. База, cookies и ключ API не уходят никуда, кроме запросов к itch.io, которые вы сами запускаете.

## Что умеет

- **Обзор** — покрытие базы, распределение оценок, годы, жанры и автоматические выводы.
- **Игры** — фильтры, сортировки и карточка игры: история оценок, места в списках «Популярное» с соседями, похожие игры, оценка просмотров.
- **Топы** — по спросу (число оценок), по отзывам (оценка с поправкой на малое число голосов), горячее, новые и растущие, featured, обсуждаемые.
- **Теги и жанры** — медианы, квантили, шанс набрать порог оценок, тренд, порог входа на первую страницу popular, каталог тегов itch.io.
- **Для разработчика** — карта возможностей по квадрантам, рейтинг ниш и форматов, сочетания тегов (lift), факторы, которые сопутствуют большему числу оценок, и «Проверка идеи»: конкуренты, медиана похожих игр и живой счётчик itch.io.
- **Разработчики** — подписчики, сумма и медиана оценок их игр, связь опыта автора с результатом.
- **Джемы** — размер, доля сдавших работу и то, как оценки внутри джема соотносятся с оценками тех же игр на itch.io.
- **Моя игра** — отслеживание позиций, загрузка своих просмотров и скачиваний по ключу API и калибровка оценки аудитории для остальных игр.
- **Экспорт** таблиц в CSV и Excel.

В шапке два общих фильтра: «18+» (по умолчанию выключен) и минимальное число оценок для медиан.

## Как читать цифры

Медианы считаются по играм, у которых оценок не меньше порога из шапки. У большинства игр itch.io оценок нет, и без этого порога медиана была бы нулём везде.

Шанс успеха — доля игр сегмента, набравших порог (по умолчанию 10 оценок), с 95% интервалом Уилсона. Знаменатель — счётчик «(N results)» со страницы списка itch.io. Пока этот счётчик не собран, доля помечена как приблизительная и завышена: в базе в первую очередь оказываются заметные игры.

Opportunity сводит спрос, шанс успеха, конкуренцию и тренд в одну шкалу 0–100. Квадранты карты сравнивают сглаженную медиану оценок с числом игр в сегменте:

| | Игр меньше медианы | Игр больше медианы |
|---|---|---|
| Спрос выше медианы | Голубой океан | Красный океан |
| Спрос ниже медианы | Тихая ниша | Ловушка |

Сочетания тегов сравниваются через lift: медиана пары, делённая на лучшую из медиан тегов по отдельности. Факторы успеха показывают сопутствие, а не причину: модель держит возраст игры постоянным, но не заменяет саму игру.

Горячее, «за 30 дней» и тренды появляются после нескольких ежедневных снимков. Сразу после быстрого старта эти колонки пустые.

## Сбор данных

Сбор идёт, только пока приложение открыто. На странице «Сбор данных» три профиля, прогресс сохраняется и продолжается со следующего запуска.

| Профиль | Зачем |
|---|---|
| Быстрый старт | Первые выводы примерно за полчаса: теги, топы по каталогу, двум последним годам, жанрам и крупным тегам. Выборка смещена к популярным играм. |
| Ежедневное обновление | Позиции в popular, новые релизы, страницы игр, профили, джемы. По расписанию раз в сутки и по кнопке «Обновить» в шапке. Если данных ещё нет, кнопка запускает быстрый старт. |
| Глубокий сбор | Оценённые игры по годам, жанрам и тегам. Списки длиннее 200 страниц дробятся по цене, жанру и платформе. Это десятки часов; за один запуск берётся ограниченная порция. |

Запросы к itch.io идут по одному, с паузой и случайным джиттером. Повторы — только для обрывов сети и ответов 5xx.

### Cloudflare

itch.io защищён Cloudflare. Если вместо страницы приходит проверка, сбор делает паузу (10, 20, затем 40 минут) и пробует снова. Когда паузы кончаются, импортируйте cookie `cf_clearance` на странице «Сбор данных».

Cookie привязан к браузеру. User-Agent в настройках на той же странице должен совпадать с браузером, из которого взят cookie. Значение хранится зашифрованным и живёт около месяца.

Запрос «сколько конкурентов» в «Проверке идеи» не ждёт эту паузу: если счётчик уже есть в базе, используется он.

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Windows, Linux или macOS. Ключи Data Protection на Windows защищаются DPAPI.

## Запуск

```bash
dotnet run --project src/ItchDB.Web
```

Приложение откроется на http://localhost:5257. База SQLite, cookies, ключи и логи создаются в `src/ItchDB.Web/data`. Этот каталог в `.gitignore`.

Другой каталог данных задаётся ключом `DataDirectory` (путь относительно проекта или абсолютный):

```bash
# PowerShell
$env:DataDirectory = "D:\ItchDB"
dotnet run --project src/ItchDB.Web
```

Тот же ключ можно положить в `src/ItchDB.Web/appsettings.json`.

Тесты:

```bash
dotnet test
```

## Ключ API

На странице «Моя игра» можно сохранить ключ с [itch.io/user/settings/api-keys](https://itch.io/user/settings/api-keys). Он шифруется через ASP.NET Data Protection и используется для одного запроса к `api.itch.io`: просмотры, скачивания и покупки ваших игр. По ним считается, сколько просмотров приходится на одну оценку, и этим числом уточняется оценка аудитории остальных игр.

## Структура

| Проект | Содержимое |
|---|---|
| `src/ItchDB.Core` | Каталог itch.io, аналитика, формулы. Без сети и базы. |
| `src/ItchDB.Infrastructure` | SQLite, HTTP-клиент, парсеры AngleSharp, сбор, загрузка датасета. |
| `src/ItchDB.Web` | Blazor Server, MudBlazor, страницы. |
| `tests/ItchDB.Tests` | Парсеры на сохранённых страницах, статистика, HTTP-клиент. |

## Ограничения

- Собираются публичные страницы itch.io. Просмотры и скачивания чужих игр площадка не показывает, поэтому аудитория — оценка.
- Пока глубокий сбор не закончен, медианы и доли успеха завышены. Страницы пишут об этом прямо.
- Часть фильтров itch.io не поддерживает (несуществующий год, слишком узкая комбинация). Такие списки пропускаются, а не записываются как пустые.
- Приложение не связано с itch.io и использует публичные страницы и официальный API только для статистики вашего аккаунта.
